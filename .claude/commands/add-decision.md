`docs/decisions.md` 파일 **끝에** 새 결정 항목을 추가하세요. (이 문서는 append-only이며, 기존 항목은 절대 수정·삭제하지 않습니다.)

사용자가 넘긴 내용: **$ARGUMENTS**

다음 형식으로 한 항목을 추가합니다:

```
### [오늘 날짜(YYYY-MM-DD)] {결정 제목}
- **결정**: {무엇을 결정했는지}
- **이유**: {왜 그렇게 결정했는지}
- **출처**: {권위 있는 출처. 없으면 "팀 내부 결정"}
```

규칙:
- 날짜는 오늘 날짜를 `YYYY-MM-DD` 형식으로 넣습니다.
- 사용자가 넘긴 내용에서 결정/이유/출처를 분리해 채웁니다. 일부가 빠졌으면 사용자에게 보완을 요청하되, 출처가 비면 "팀 내부 결정"으로 둘 수 있습니다.
- 위험 가중치·임계값에 관한 결정이라면 **출처가 반드시 권위 있는 공식 출처**(HUG·정부·금융기관·판례)인지 확인합니다.
- 파일 끝에만 추가하고, 기존 내용은 건드리지 않습니다.
