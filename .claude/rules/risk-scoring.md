# 규칙: 위험 점수 (risk-scoring)

> 위험 점수·등급 로직을 다룰 때 **항상** 지켜야 하는 규칙입니다.

## 1. 출처 없는 수치 금지
- 모든 **위험 가중치·임계값**(예: 전세가율 80%, 선순위채권비율 60% 등)은 **`docs/decisions.md`에 출처와 함께 기록된 값만** 사용한다.
- 팀의 추측·감(感)으로 정한 임의의 수치는 코드에 절대 넣지 않는다.
- 새 기준이 필요하면 먼저 권위 있는 출처(HUG·정부·금융기관·판례)를 찾고, `/add-decision`으로 기록한 뒤 사용한다.

## 2. 권위 있는 출처만 인정
- 인정되는 출처 예시: **HUG 공식 기준**, 정부/금융기관의 **전세가율·선순위채권비율 기준**, **판례**, 관련 법령.
- 블로그·커뮤니티 글 등 비공식 출처는 단독 근거로 사용하지 않는다.

## 3. 보수적 편향 — 경고 우선
- 판단이 애매하거나 데이터가 불충분할 때는 **안전(저위험)으로 단정하지 말고 경고(고위험) 쪽으로** 편향한다.
- **false negative(위험을 놓침)** 를 최소화하는 것이 최우선 목표다.
- "안전합니다" 같은 단언보다 "확인이 필요합니다 / 주의가 필요합니다" 같은 보수적 표현을 사용한다.

## 4. 설명 가능성
- 모든 위험 판단은 **왜 그렇게 판단했는지 근거를 함께 출력**할 수 있어야 한다. (규칙 기반 + RAG를 택한 핵심 이유)
- 점수에 기여한 각 항목과 그 출처를 추적할 수 있게 구조화한다.

## 5. 방식
- ML 분류 모델을 쓰지 않는다. **규칙 기반 + 향후 RAG**만 사용한다.
