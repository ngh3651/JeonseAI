## 4. 전략 (팀 결정, 2026-10-21)

- 목표는 입상이 아니라 **킨텍스에서 부끄럽지 않게**. 발표는 기술보다 **방향성·페르소나·참여형**.
- 대신 **질의응답에서 무너지지 않을 실물**이 있어야 한다 → 개발(남규혁)의 몫.
- 포장(현수막·포스터·부스 참여 아이템·영상·PPT) = 이영호 팀대표 + 팀원.
- 안 한 것을 했다고 말하지 않는다. 현장에서 본선보다 **발전된 실물**을 보여준다.
