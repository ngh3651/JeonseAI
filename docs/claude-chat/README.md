# Claude Chat 인박스 (docs/claude-chat/)

> **Claude Chat(프로젝트 지식) → 저장소** 방향의 반입 창구입니다.
> Claude Chat에서 확정된 결정·자료(부동산 인터뷰 정리본 포함)가 이 폴더에 파일로 들어옵니다.

## 배경

Claude Chat은 GitHub 동기화로 이 저장소의 문서(plan.md, decisions.md 등)를 읽으며
보고서·발표자료·기획 문서를 만든다. 반대 방향 — 채팅에서 확정된 자료가 저장소로
들어오는 길목이 이 폴더다.

## 운영 규칙

1. **유입**: Claude Chat 쪽에서 확정된 문서가 마크다운 파일로 추가된다.
   파일명은 `YYYY-MM-DD-주제.md` 형식을 권장.
2. **확인**: Claude Code는 세션 시작 시 이 폴더의 새 파일을 확인한다.
3. **반영 원칙 (기존 원칙 그대로)**:
   - 인터뷰 등 **비공식 출처**는 **비판정 계층**(리포트 문구, 중개사 질문, 조언,
     UX 카피)에만 반영한다.
   - **판정 기준(임계값·가중치·등급)**에는 권위 출처(HUG·정부·금융기관·판례·법령)
     없이 절대 넣지 않는다 — `.claude/rules/risk-scoring.md` 준수.
   - 반영이 결정으로 이어지면 `/add-decision`으로 `docs/decisions.md`에 기록한다.
     인터뷰가 계기라면 "바꾼 이유"에 그 사실을 명시한다.
4. **역방향 참고**: 저장소 → Claude Chat 방향은 GitHub 동기화가 담당한다.
   decisions.md가 [처음 의도 → 바꾼 이유 → 최종 결정] 스토리 형식으로 기록되는
   이유이기도 하다 (발표자료의 원재료).

## 예정 유입물

- 부동산 중개인 현장 인터뷰 정리본 (최가은 담당) — 도착 시 질문 생성기
  (`backend/data/questions.json`) 문구·조언 계층 반영 후보
