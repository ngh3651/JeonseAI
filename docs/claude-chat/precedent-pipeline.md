## Step 1. Case Collection

**About the API KEY**

국가법령정보 공동활용 Open API KEY로 판례 목록조회 및 본문조회
**법제처 운영 국내 서비스**

**목록조회 및 본문조회 활용 방안**

API KEY 및 검색어 → 목록조회 → 판례 리스트 및 **판례 일련번호** 획득 → 본문조회

**About the Data**

판례 하나가 **구조화된 15개 항목**으로 나누어 제공됨
Metadata: 사건번호 · 선고일자 · 법원명 등 (출처 표기용)
판례 내용: 판시사항 · 판결요지 · 참조조문 등
→ 받은 **원본 그대로 저장** 후 가공

**About 증분 갱신** (구현 예정)

마지막 수집 이후 새로 등록 · 수정된 판례만 추가 수집
**선고일 최신순 조회 → 이미 가진 판례 만나면 종료**
