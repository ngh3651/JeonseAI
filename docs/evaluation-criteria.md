# 대회 공식 평가 기준 (evaluation-criteria.md)

> **출처**: 2026 AI ROOKIE 본선 제안서 양식(HWP)에서 추출한 공식 배점·연계 항목.
> 이 문서에 없는 배점·기준을 임의로 추가하지 않는다. 대회 측 공지가 갱신되면
> 이 문서를 먼저 갱신한 뒤 `judge-reviewer` 등에서 참조한다.

## 공식 배점 (총 100점)

| 대분류 | 배점 | 세부 항목 | 배점 |
|---|---|---|---|
| **도전성** | 50 | 창의성 | 30 |
| | | 혁신성 | 20 |
| **팀역량** | 50 | 추진성 | 30 |
| | | 성장성 | 20 |

---

## 1. 창의성 (30점)

**의미**: 문제 정의의 참신함, 기존 서비스(안심전세앱 등) 대비 차별점, 기능·구성의 독창성.

**제안서 연계 섹션**: 1.2 한줄요약 / 1.5 차별점 / 3.1.2 기능명세 / 3.2.2 기능개요

**전세AI프 체크포인트**:
- 판례 매칭·손실 시뮬레이터·질문 생성기가 안심전세앱과 **확실히 구별**되는가

## 2. 혁신성 (20점)

**의미**: 최신 AI 트렌드(생성AI·AI에이전트·RAG) 반영, 기술 동향 근거, 구현 결과 우수성(정량 지표), 신뢰성·윤리(편향·환각·악용 대응).

**제안서 연계 섹션**: 1.4 기술동향 / 3.3.1 구현검증 / 3.3.4 신뢰성·윤리

**전세AI프 체크포인트**:
- 규칙엔진+LLM 가드레일·보수적 편향·RAG가 **"신뢰성·윤리" 점수로 드러나는가**
  (우리 강점 — 반드시 짚을 것)

## 3. 추진성 (30점)

**의미**: 동작하는 데모 + 진척도(%), 목표 대비 구현 수준, 테스트·검증, 사전 구현 성과의 실체.

**제안서 연계 섹션**: 3.1.1 개발목표 / 3.1.4 사전구현성과 / 3.2.3 개발현황 / 3.2.4 진척도

**전세AI프 체크포인트**:
- 실제 동작(추출→판정→설명)이 데모에 보이는가, 진척도를 %로 말할 수 있는가

## 4. 성장성 (20점)

**의미**: 향후 확장·적용 가능성, 한계점 보완 계획, 팀 학습 성과(교육·멘토링).

**제안서 연계 섹션**: 3.1.5 향후계획 / 3.3.3 학습성과 / 5.2 확장가능성

**전세AI프 체크포인트**:
- CODEF·법제처 RAG 등 백로그가 **"확장 계획"으로 설득력 있게 제시**되는가

## 사용 방법

- `.claude/agents/judge-reviewer.md`가 이 문서를 채점 기준으로 삼는다
  (방식은 `rule-auditor`가 `docs/decisions.md`를 근거로 감사하는 것과 동일).
- Phase B(스코프 검증), Phase F(데모 시나리오·리허설)에서 이 배점 기준으로 채점한다.
- 배점·연계 섹션 자체를 바꿀 권한은 이 문서에 없다 — 대회 공지 원문이 바뀌면
  그 근거를 명시하며 이 문서를 갱신한다.
