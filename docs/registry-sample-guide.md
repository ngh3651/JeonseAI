# 테스트용 '위험 신호 있는' 등기부 구하는 법 (팀 전달용)

> Phase E 실기기 테스트와 Phase F 시연에는 **위험 신호(근저당·압류·신탁 등)가 실제로 붙어 있는
> 진짜 등기부등본**이 필요합니다. 가짜 데이터를 만드는 게 아니라, 아래 절차로 실물을 확보합니다.
> 1부당 열람 700원 / 발급 1,000원이 듭니다.

## 절차 (10분 코스)

1. **법원경매정보** (www.courtauction.go.kr) 접속 → "경매물건" 검색
   - 지역(예: 서울/경기)과 용도(다세대·오피스텔·아파트)를 골라 검색한다.
   - **경매가 진행 중인 물건은 등기부에 근저당·압류·경매개시결정이 실제로 붙어 있을 확률이 높다.**
   - 물건 상세 화면에서 **소재지 주소**를 복사한다. (동·호수까지)
2. **인터넷등기소** (www.iros.go.kr) 접속 → 부동산 등기 "열람/발급" → 주소 입력
   - 열람(700원, PDF 보기)이면 테스트에 충분하다. 결제 후 **PDF로 저장**한다.
3. PDF를 팀 공유 폴더에 올리고, 파일명에 유형을 적는다. (예: `근저당과다_서울OO동.pdf`)
   - 앱 테스트 시에는 PDF 각 페이지를 캡처하거나 출력해 촬영하면 된다.

## 확보 목표 (유형별 1부씩)

| 유형 | 찾는 법 |
|---|---|
| 근저당 과다 | 경매 물건 대부분 해당 |
| 압류·가압류 | 경매 물건 상세의 등기 현황에서 확인 후 선택 |
| 신탁등기 | 경매 검색에서 '신탁' 관련 물건, 또는 신축 오피스텔·빌라 |
| 깨끗한 집 (대조군) | 팀원 본인·가족 자택 등기부 |

## 주의

- 등기부는 누구나 열람할 수 있는 공적 장부지만, **소유자 실명 등 개인정보가 포함**된다.
  팀 외부 공유·SNS 업로드 금지. 시연 영상에 쓸 때 이름 처리(모자이크)는 Phase F에서 결정한다.
- 열람용 PDF에는 워터마크가 있을 수 있으나 추출 테스트에는 지장 없다.
