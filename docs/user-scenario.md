## 표기법

- `[버튼]` = 탭 가능한 UI 요소, `→` = 화면 전환/상태 변화

## 1. 핵심 시나리오 A — 지수의 첫 분석 (**시연 메인 경로**)

> 26세 사회초년생 지수. 내일 중개사무소 방문 예정. 등기부등본 사진 3장을 받아둔 상태.
> 🎬 차별화 3종(판례·시뮬레이터·질문 생성기)과 가드레일(챗봇 거절)을 모두 경유하는 대본.
> A1~A3(온보딩·가입·홈)은 영상에서 배속/생략 가능.

| A12 | 뒤로 → S-07 → S-09 | [손실 시뮬레이터] → 슬라이더 조작 | 🎬 기억에 남을 컷: 💬 "집이 경매로 넘어가 이 가격에 팔린다면?" 슬라이더 → 예상 손실 실시간 변동 → [보증보험 가입 시] 토글 → 0원 |

**성공 기준 (지수 체크리스트)**: 각 화면 3초 내 다음 행동 인지 / 전문용어 무설명 노출 0건 (제목·버튼·칩 포함) / 경고가 행동 지침으로 연결 / 보수적 문구에는 항상 다음 행동 버튼이 짝지어짐.

> 31세 신혼 서연. 지난주 매물 A(등급: 위험) 분석 완료. 오늘 매물 B를 보고 나온 직후.

| # | 화면 | 행동 | 결과 |
|---|---|---|---|
| B1 | 앱 실행 | 로그인 유지 상태 | 스플래시 → 바로 S-03 홈 |
| B2 | S-03 | 이력에서 매물 A 카드 확인 (자동 별칭 주소·분석일·등급 뱃지·최대 위험 요인 한 줄) | 카드 탭 → S-07 재열람. 상단 배너 💬 "7일 전 분석 결과예요. 계약 직전에는 최신 등기부로 다시 확인하세요" + [재분석] |

**성공 기준 (서연 체크리스트)**: 홈→기존 리포트 **1탭** / 공유 이미지 단독으로 매물·시점·결론 식별 가능 / 근거 펼침에 출처 표시 / 이력 카드만으로 두 매물의 차이 인지 가능.

## 4. 화면별 상세 시나리오 (버튼→액션)

### S-02 로그인/시작
- [로그인]: 이메일·비밀번호 → 즉시 성공(목업) → S-03. ⚠ 빈 입력 시 인라인 안내
- [회원가입]: 이름·이메일·비밀번호 → 즉시 성공(목업) → S-03
- [비회원으로 시작하기] → S-03 (비회원 모드)
- 이력·체크 상태는 **기기 로컬 단일 저장, 계정 구분 없음** (목업 한계 — 로그아웃 후 다른 이름으로 로그인해도 동일 데이터 표시. 시연에서 계정 전환 연출은 하지 않음)

### S-04 매물 검색
- [등기부 업로드 | 주소 검색] 세그먼트 전환
- [사진 추가] → ⚠ **권한 분기**: 카메라/사진 권한 거부 시 💬 "사진을 불러오려면 권한이 필요해요" + [설정으로 이동]
- 입력 필드: **예정 보증금(필수)** / 시세(선택 — 💬 "국토부 실거래가·KB시세 등에서 확인한 금액을 입력하면 더 정확해져요") / 별칭(선택 — 미입력 시 표제부 주소 자동)
- 사진 0장 또는 보증금 미입력 상태에서 [분석하기] 비활성 + 인라인 안내
- 10장 초과 추가 시도 → 💬 "사진은 최대 10장까지 올릴 수 있어요"
- [등기부등본이 없어요] → S-05 발급 가이드
- ⚠ 뒤로가기로 이탈 후 재진입: 선택한 사진·입력값 세션 복원
- 주소 검색 탭: 검색 시 💬 "주소만 입력하면 등기부를 자동으로 조회하는 기능을 다음 버전에서 준비하고 있어요 (공공 데이터 연동)" + [업로드로 이동]

### S-05 등기부 발급 가이드
- 단계 카드: ① 인터넷등기소 접속(비회원 가능) ② 주소 입력 → **'열람' 선택 (수수료 700원 — 분석에는 열람용으로 충분, 금액은 인터넷등기소 고시 기준으로 Phase C에서 원문 재확인)** ③ 결제 후 PDF 화면 캡처 or 출력물 촬영 ④ 앱에 업로드
- 하단 [준비됐어요, 분석 시작] → 회원: S-04 / 비회원: 로그인 유도 바텀시트

### S-06 분석 로딩
- 단계 인디케이터 4단계 (판정 주체 구분 문구 — IA §6). 추출 항목 실시간 표시. 💬 "보통 1~2분 걸려요"
- ⚠ 시스템 백/[취소]: 확인 다이얼로그 💬 "분석을 중단할까요? 처음부터 다시 해야 해요" → [계속하기] / [중단] → S-04 (사진·입력값 유지)
- ⚠ **백그라운드 전환 (홈 버튼·전화 수신)**: 분석 계속 진행, 복귀 시 로딩/완료 화면 재표시. OS가 프로세스를 종료한 경우 S-04(사진·입력값 복원)로 복귀
- ⚠ **타임아웃**: 일정 시간(예: 3분) 초과 무응답 시 네트워크 오류와 동일 분기
- ⚠ **네트워크 오류**: 💬 "연결이 불안정해요. 다시 시도해 주세요" + [다시 시도] (재선택 불필요) / [나중에 하기] → S-04
- ⚠ **재시도 불가 오류 (API 한도 초과 등)**: 💬 "지금은 분석이 어려워요. 잠시 후 다시 이용해 주세요" — [다시 시도] 버튼 없음 (무한 재시도 루프 방지)
- ⚠ **추출 실패 (등기부가 아닌 이미지 등)**: 💬 "등기부등본을 찾지 못했어요. 사진이 선명한지, 등기부등본이 맞는지 확인해 주세요" + [사진 다시 고르기] → S-04. **모호한 실패도 이 쪽으로 처리** (부분 결과로 안전 단정 금지 — 보수적 편향)
- ⚠ **불완전 등기부 (갑구/을구 페이지 누락)**: 리포트는 진행하되 해당 근거 카드를 **"페이지 누락 — 등기부 ○구 페이지를 추가로 촬영해 주세요" 상태**로 표기 + [사진 추가하기] → S-04. (을구 없음을 '근저당 없음'으로 판정하지 않는다 — 보수적 편향)

### S-07 AI 안전도 리포트
- 결론 헤더: 등급(크게) + 한 줄 결론 + 등급별 "지금 해야 할 일" (IA §6 등급 슬롯 표 참조 — 위험=회피 권고 / 확인 필요=보류·추가 확인 / 양호=진행 검토 가능·단정 금지)
- 근거 카드 (기본 접힘, 제목은 쉬운 질문형 + 전문용어 부제 — IA §6 목록): 탭하면 펼침 — 쉬운 설명 → 수치 → 출처 + `판정: 규칙 기반 (출처)` / `설명: AI 생성` 라벨
  - ⚠ 데이터 불충분 항목 (시세 미입력 등): "확인 필요" 상태 + 💬 "이 항목은 ○○을 입력/확인하면 알 수 있어요" + 해당 행동 버튼 (안전으로 표시 금지)
  - ⚠ 악성임대인 대조: 명단에 없어도 💬 "공개 명단에서 발견되지 않았어요 (명단에 없다고 안전이 보장되는 건 아니에요) — 아래 질문으로 직접 확인하세요" + [질문 생성기]
- 밑줄 용어 탭 → 바텀시트 (2~3문장 + [챗봇에 더 물어보기] → S-12 push, 뒤로가기 = S-07)
- 다음 행동: [질문 생성기] [판례 보기] [손실 시뮬레이터] [체크리스트] (모두 push, 뒤로 = S-07)
- 이력 재열람 시: "○일 전 분석" 배너 + [재분석] (→ S-04에 기존 입력값 채워진 상태)
- [공유]: [요약 이미지] / [전체 리포트 이미지] 선택 → 생성 → 시스템 공유 시트. ⚠ 생성 실패 시 토스트 💬 "잠시 후 다시 시도해 주세요"

### S-08 판례 매칭
- 상단: 현재 매물의 위험 패턴 칩 → 패턴별 판례 카드 (사건 한 줄 요약·결과·우리 매물과의 공통점)
- 카드 탭 → 상세 (요약 전문 + 출처 표기)
- ⚠ 빈 상태: 💬 "이 매물의 위험 패턴과 일치하는 판례가 아직 없어요. 위험이 없다는 뜻은 아니니, 중개사에게 확인할 질문을 챙겨 가세요" + [질문 생성기] + 💬 "판례 데이터는 계속 추가되고 있어요"

### S-09 손실 시뮬레이터
- 슬라이더 💬 "집이 경매로 넘어가 이 가격에 팔린다면?" ('낙찰가율'은 부제+툴팁) → 예상 손실액·회수액 실시간 갱신, [보증보험 가입 시] 비교 토글
- 기본값·계산식은 E-4에서 출처 확정 (더미 단계에서는 표시값에 "예시" 워터마크)

### S-10 질문 생성기
- 위험 요소 그룹별 질문 카드: 질문 + 이유 한 줄 (💬 "신탁등기가 있으면 집주인 마음대로 계약 못 할 수 있어요") + **판별 가이드** (💬 "이런 답이면 안심: 신탁원부를 바로 보여준다 / 이런 답이면 보류: 확인해 줄 수 없다고 한다")
- [개별 복사] / [전체 복사] → 토스트 💬 "복사했어요. 중개사무소에서 그대로 보여주세요"
- ⚠ 위험 요소가 없을 때: 기본 질문 세트 (💬 "어떤 집이든 꼭 물어봐야 할 질문이에요")

### S-11 계약 여정 체크리스트
- 첫 진입: "지금 어디쯤이세요?" 단계 선택 → 해당 단계 강조 (이후 변경 가능)
- 단계 아코디언 (단계명 + 쉬운 부제): 계약 전 → 계약 체결 → 잔금일("나머지 보증금을 보내는 날") → 입주(전입신고·확정일자) → 보증보험 가입 → 만기 전 → 보증금 반환
- 항목 체크 → 회원: 로컬 저장 / 비회원: 세션만 (C3) / 각 항목 "왜 해야 하나요?" 펼침

### S-12 용어 챗봇
- 진입 시 추천 질문 칩 6개 (신탁등기·근저당·갑구/을구·확정일자·대항력·우선변제권)
- 질문 입력 → 응답 (용어·개념 설명만)
- ⚠ 범위 밖 질문 ("이 집 계약해도 돼요?"): 💬 "저는 용어를 쉽게 설명해 드리는 챗봇이에요. 매물의 위험 판단은 규칙 기반 안전도 리포트가 맡고 있어요" + 분기: 이력 있음 → [내 리포트 보기] / 이력 없음·비회원 → [매물 분석하러 가기] (비회원은 로그인 유도 바텀시트) — **챗봇이 판정·조언을 생성하지 않음 (가드레일)**
- ⚠ 네트워크 오류: 말풍선 자리에 [다시 시도]

### S-13 마이/설정
- 분석 이력 전체 목록 → 카드 탭 = S-07 재열람 / 삭제 (확인 다이얼로그 💬 "삭제하면 되돌릴 수 없어요")
- [로그아웃] → 확인 → S-02
- 비회원일 때: 프로필 자리에 [로그인하고 이력 저장하기]

## 5. 공통 예외 규칙

| 상황 | 처리 |
|---|---|
| 네트워크 없음 (분석·챗봇 등 서버 필요 기능) | 인라인 에러 + [다시 시도]. 앱 전체를 막는 풀스크린 에러는 쓰지 않음 |
